A quick, simple way to check if your audio output is working. Run `beep` to play a short chime.

Supports Windows and Linux.

## Install

Download the binary for your system from [Releases](https://github.com/coalaura/beep/releases), rename it to `beep` (or `beep.exe` on Windows), and place it on your `PATH`. On Linux, make it executable with `chmod +x beep`.

## Usage

```sh
beep
```

No options or configuration needed.
